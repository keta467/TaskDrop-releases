# TaskDrop Releases

TaskDropのmacOS / Windows向けインストーラーと、自動更新データを公開するリポジトリです。

## ダウンロード

- [macOS版（Apple Silicon）](https://github.com/keta467/TaskDrop-releases/releases/latest/download/TaskDrop-macOS.dmg)
- [Windows版（64bit）](https://github.com/keta467/TaskDrop-releases/releases/latest/download/TaskDrop-Windows-setup.exe)

最新版は[Releases](https://github.com/keta467/TaskDrop-releases/releases/latest)からも確認できます。

このリポジトリに開発ソースは含まれません。インストーラー、更新用アーカイブ、署名、`latest.json` は非公開の開発リポジトリからGitHub Actionsで自動公開されます。
